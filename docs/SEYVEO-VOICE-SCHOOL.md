# SEYVEO Voice School — один фирменный женский голос

Дата: 30 октября 2026. Экспериментальная локальная лаборатория. **Не подключена к рабочим чатам и карточкам SEYVEO.** Ничего не запускается автоматически.

## Утверждённый характер

Голос, выбранный как эстетический ориентир: женский, нежный, тёплый, мягкий, слегка бархатистый; спокойная естественная русская речь с выразительными паузами и слегка смягчённой «р», без роботизации и театрального переигрывания. Это **не попытка скопировать конкретный голос ChatGPT**. SEYVEO должен иметь **один собственный узнаваемый женский голос** для всех пользователей; переключатель голосов в настройках не создаём.

## Как ИИ помогает улучшать голос

- Генератор (Qwen3-TTS VoiceDesign 1.7B) синтезирует полностью оригинальные русскоязычные голоса **по текстовому описанию**, без записи человека.
- Шесть проверочных фраз тестируют естественность формулировок, «р», числа и деловую речь.
- Распознаватель (faster-whisper) возвращает расшифровку. Детерминированная проверка считает Word Error Rate (WER), измеряет длительность, громкость и риск клиппинга. Это **автоматический технический экзамен**.
- Два лучших варианта мы можем послушать. Пользователь **один раз** выбирает понравившийся голос. Программа сохраняет сгенерированный эталон (selected-reference.wav), а отдельная Qwen3-TTS Base далее использует этот эталон для новых фраз. Так меняется интеллект SEYVEO, а голос остаётся узнаваемым.
- Самостоятельные проверки могут со временем выявлять речевые дефекты. Технический экзамен НЕ оценивает красоту, эмоциональную искренность и не обучает веса модели. Не надо бесконтрольно менять эталон после каждого экзамена.

Только синтетический материал. Не копировать голос ChatGPT, не подгружать чужие голоса или личные аудиосообщения сотрудников без явного согласия и прав.

## Что доступно сразу, без установки больших моделей

В Python 3.11 из корня репозитория:

    python server/seyveo-voice-school/voice_school.py --plan
    python -m unittest discover -s server/seyveo-voice-school -p test_voice_school.py -v

Для этих команд не нужны сеть, Ollama, микрофон, видеокарта или сторонние Python-пакеты.

## Как попробовать реальные голоса

Экспериментальный движок: Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign (Apache 2.0, русский язык).
Нужна отдельная Python-среда с совместимыми версиями torch, qwen-tts, soundfile, faster-whisper. На ПК Intel i5 с 32 ГБ и без видеокарты режим CPU может быть **очень медленным** и потребует много памяти; не ставим регулярную генерацию на фоне. Возможны проблемы совместимости на Windows. Лучше сначала использовать облачный GPU или другое оборудованное устройство для генерации эталонного WAV, затем проверять локально.

После самостоятельной установки зависимостей и явного согласия на скачивание весов:

    python server/seyveo-voice-school/voice_school.py --generate --count 2 --cpu

Первый запуск может скачать большие модели Qwen3-TTS и Whisper из Hugging Face; это не отправка пользовательских записей, но требует доступа в интернет. Синтез идёт локально; после загрузки моделей внешняя передача аудио не требуется.

Результаты лежат вне репозитория:

    %LOCALAPPDATA%\SEYVEO\voice-school\
        voice_1_hello.wav
        voice_1_business.wav
        ...
        report.json

Прослушайте кандидатов. **Только после выбора** закрепите один:

    python server/seyveo-voice-school/voice_school.py --lock voice_1

Эта операция копирует синтетический эталон в selected-reference.wav.

Для пробного воспроизведения того же тембра (после установки Qwen3-TTS Base):

    python server/seyveo-voice-school/speak.py --cpu

Результат: seyveo-test.wav в той же локальной папке. Это не продакшен, качество/стабильность на CPU ещё не проверены; Base может заново загрузить веса из интернета. Путь выбранного голоса не коммитится в GitHub.

## Что нельзя считать завершённым

- Модель не обучала собственные веса на аудио и не стала «умнее» автоматически.
- Рабочая Сэйви на iOS/Android ещё не умеет использовать этот WAV или нативный звук; нужна отдельная интеграция TTS и ASR.
- Нет голосового разговора с прерыванием, определения эмоций по микрофону, распознавания говорящего и корректировки произношения в реальном времени.
- Проверка ASR может ошибиться; низкий WER не гарантирует красивый голос и наоборот.
- Отдельные произношения и эмоциональность потребуют дополнительного голосового экзамена и, возможно, контролируемого fine-tuning с разрешёнными аудиоданными. Копировать голос другого человека нельзя.

Поскольку целью SEYVEO является личный помощник с одним фирменным голосом, пользователь может менять «отношение/стиль общения», но это **не должно переключать голос или менять его личность**.
