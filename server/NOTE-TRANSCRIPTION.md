# SEYVEO · Распознавание сохранённых аудиозаписей

Локальный модуль Whisper позволяет перевести в текст любую голосовую запись из
умного блокнота — даже спустя несколько дней. Исходное аудио остаётся в заметке.

## Установка на Windows

1. В GitHub Desktop открой репозиторий SEYVEO и нажми **Fetch origin → Pull origin**.
2. Открой папку проекта → `server`.
3. Дважды нажми **`install-note-transcription.cmd`**. Установщик создаёт отдельную
   среду Python 3.11 (`server/.venv-seyveo-asr`), устанавливает `faster-whisper`
   и скачивает русскоязычную модель `small` (около 500 МБ). Это одноразовая установка.
4. После надписи «Готово» перезапусти SEYVEO привычным ярлыком на рабочем столе.
5. Открой **http://127.0.0.1:8790** → Блокнот → заметка → аудиозапись →
   **«Распознать»**. Текст автоматически добавится в эту же заметку — без
   отдельного окна. Кнопка **«Отменить»** доступна 10 секунд; оригинальное
   аудио остаётся на месте. Если Сэйви ошиблась, текст можно исправить прямо в заметке.

**Без микрофона на ПК:** запиши голос в «Диктофоне» iPhone, перенеси M4A-файл
на компьютер, затем в локальном блокноте нажми **скрепку → Файл** и выбери
его. Отдельной кнопки «Аудиофайл» нет: SEYVEO сам покажет аудиокапсулу
с воспроизведением и **«Распознать»**. Также подходят MP3, WAV, WebM и OGG.

Если Python не установлен, сначала установи Python 3.11 и повтори пункт 3.

## Принципы

- Файл временно передаётся **только локальному процессу на том же ПК**.
- Движок читает аудио из временной папки. По окончании запроса временный файл удаляется.
- Модель может потребовать интернет **при первой установке**, но сами записи не
  передаются в онлайн-сервисы.
- Данные хранятся локально в браузере, как и другие вложения блокнота.
- Поддерживаются WebM, M4A/MP4, OGG, WAV и MP3 размером до 10 МБ, до пяти минут.
- Публичная версия на GitHub Pages и iPhone **не имеют доступа** к локальному
  ПК-движку. Для этих устройств потребуется отдельная защищённая серверная
  архитектура; отправка аудио в сторонние сервисы не включена.
