# SEYVEO · Проверка русского ударения

**Статус: экспериментальная языковая лаборатория, не часть озвучки.**

## Зачем

На одинаковом голосе Qwen3-TTS мы услышали:
- «Дверной замок сломался» — правильное **замо́к**.
- «На входной двери установлен запор. Дверной замок сломался» — неправильное **за́мок**.
- Разметка U+0301 иногда искажает слово («залмок»).

Пока нет доказанного способа надёжно передать ударение именно в **нынешнюю утверждённую** Qwen3-TTS. Поэтому ни этот скрипт, ни его вывод не меняют текст TTS автоматически.

## Самый простой запуск на Windows

После **Pull origin** открой файл:

`server/run-russian-stress-lab.cmd`

Он сам подготовит **отдельное** Python-окружение для русского языка. Если RUAccent ещё не установлен, спросит разрешение на загрузку стороннего пакета. Затем обработает контрольные фразы и сохранит `stress-report.jsonl` в корне проекта.

Это эксперимент для оценки ударений, **не изменение обычной речи Сэйви**. Первый запуск RUAccent может занять время и потребовать интернет.

## Массовый анализ (добровольный)

1. При необходимости установи сторонний RUAccent в **отдельное** Python-окружение, а не в голосовой движок:
   `py -3.11 -m venv .venv-ru-stress`
   `.venv-ru-stress\Scripts\python.exe -m pip install ruaccent`
2. Чтобы проверить только структуру отчёта **без установки**:
   `py -3.11 server/russian-stress-batch.py --dry-run`
3. Чтобы обработать 12 тестовых предложений:
   `.venv-ru-stress\Scripts\python.exe server/russian-stress-batch.py`
4. Чтобы проверить свои предложения, сохрани UTF-8 файл (одна фраза на строку):
   `.venv-ru-stress\Scripts\python.exe server/russian-stress-batch.py --input phrases.txt --output stress-report.jsonl`

Первый запуск RUAccent может скачать словарь или дополнительные файлы модели.
Скрипт не отправляет текст в облачный API, однако установка зависимостей и первоначальная загрузка моделей обращаются к внешним источникам.

Файл `stress-report.jsonl` — машинный отчёт: исходный текст, предсказанные ударения, сравнение с несколькими эталонными примерами. **Совпадение с эталоном не гарантирует правильного звучания TTS.** Для неизвестных фраз статус `review`.
