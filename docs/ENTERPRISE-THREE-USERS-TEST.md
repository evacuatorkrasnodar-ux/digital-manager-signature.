# SEYVEO Enterprise — испытание трёх участников

Тест: `node --test server/tests/enterprise-three-users.test.mjs` из корня репозитория.

Сценарий: фиктивный директор выдаёт два независимых 15-минутных приглашения для Елены и Татьяны; они погашаются один раз; посторонний не может выдавать приглашения или отзывать других; отзыв Елены вызывает аннулирование её учебных сессий и не блокирует Татьяну.

Это **тест уже существующего локального модуля** `server/secure-documents/dev-invitations.mjs`. Это не OIDC, не подтверждение доставки на два телефона, не публичный API и не защищённый production-сервер. Не запускать loopback dev-server на открытом интерфейсе.

Для настоящего пилота всё ещё требуются: проверенный провайдер OIDC, серверные роли и tenant isolation на каждом запросе, хранение членства, TLS, отдельный доступ к рабочим файлам, тест с двумя устройствами и отзыв токенов.
