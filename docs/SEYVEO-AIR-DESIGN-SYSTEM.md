# SEYVEO Air — единый стандарт интерфейса
**Статус: утверждено владельцем · 02.11.2026 · версия 1.0**

## Цель
Один спокойный, воздушный и премиальный язык для SEYVEO One, Business, Browser и встроенных инструментов на iOS/Android. Ориентир — ясность и естественность интерфейсов Apple, **не буквальное копирование** их компонентов. Любой экран должен ощущаться частью единого приложения.

**Эталонные экраны на 02.11.2026:** Главная SEYVEO и «Мой мир». В остальных разделах новые решения должны наследовать их лёгкость.

## Неподвижные правила
1. **Непрерывный фон темы:** один холст на экран; никаких фотографий-фонов, сеток «серых коробок», случайных дополнительных плашек, толстых бордюров и светящихся кантов.
2. **Плоские поверхности по умолчанию:** контент на самом холсте; группировку обеспечивают интервалы, типографика и редкие тонкие разделители. Выделенная панель разрешена только для настоящего модального действия, важного состояния либо специально согласованного дока.
3. **Типографика вместо декора:** компактные ясные заголовки, один ритм отступов, короткие названия; не показывать повторяющиеся служебные, маркетинговые и демо-подписи.
4. **Единое семейство значков:** контурные, одинаковой визуальной массы, близко к 1.35px в масштабе 24px. Сохранять размер и цветовые акценты без цветных квадратов под каждой иконкой. Тексты не окрашивать в цвет темы.
5. **Лёгкие интерактивные элементы:** почти невидимый фон и отсутствие «выпуклости»; зона касания минимум 44×44 CSS px, заметный focus-visible, ясные disabled/pressed/selected состояния. Не жертвовать доступностью ради тонкости.
6. **Три пользовательские темы:** Белая (по умолчанию), Графит Black Velvet и Изумруд HDR. Любая правка проверяется во всех трёх. В коде пока могут существовать дополнительные старые palette ID — не удалять их без миграции.
7. **Исключение — фирменный бархатистый док:** сохраняем размер, форму, материал и привычную механику, но без декоративного светящегося обода. Не распространять его объёмность на остальные кнопки.
8. **Характер SEYVEO:** сфера — узнаваемый акцент. **Музыкальная виниловая пластинка упразднена решением владельца 02.11.2026:** Музыка использует настоящую обложку файла при её наличии, иначе плоский контурный символ. Никаких наградных звёзд и «Аллеи славы»; только лаконичное сердечко и «Избранное». На других страницах музыка показывается компактной строкой Now Playing с обложкой, названием, паузой и прогрессом, без винила. Сфера и док не копируются в мини-плеер.
9. **Единая навигация:** одинаковый возврат и жесты, одна понятная верхняя панель и один док; не создавать дубль управления в каждом разделе. Сохранять доступность и контекст при переходах.
10. **Работающие функции важнее макета:** не удалять настоящие действия, права доступа, черновики, избранное и данные. Интерфейс должен ясно обозначать неподключённые интеграции, но без постоянных экранов «демо».

## Технический контракт
- **Сначала удалить конфликтующие старые стили, потом править исходные правила.** Не добавлять ещё одну переопределяющую CSS-надстройку поверх той же секции.
- Один ответственный CSS-модуль за геометрию каждого экрана; общие переменные и доступность — в `assets/seyveo-velvet-system.css`. Экран «Мой мир» — `assets/life-tiles-accents.css` для текущей сетки.
- Единые базовые токены: `--sv-air-icon-stroke` = 1.35, `--sv-air-touch-target` = 44px, `--sv-air-row-height` = 70px, `--sv-air-divider` = линия текущей темы. Не жёстко прописывать их отдельно во всех разделах.
- Любые эффекты уважительно относятся к `prefers-reduced-motion`, текст — к доступному контрасту и масштабированию.
- Не переносить файлы пользователя в облако без разрешения. Не изображать неподключённые сервисы работающими.
- При изменении CSS/JS обновлять версию ресурса в `index.html`, проверять синтаксис, селекторы, aria, маршруты, действия, темы и касания.
- Прототип проверять на узком телефоне (включая iPhone X и safe area), современном iPhone, Android и десктопе; визуальную проверку не выдавать за проведённую, пока нет реального скриншота/рендера.

## Очерёдность модернизации
1. **Основа** — правила, токены и удаление дублирующих стилей.
2. **Главная и Мой мир** — эталонные макеты, устранение конфликтов без перемены композиции.
3. **Музыка** — лёгкий плеер, пластинка, «Избранное» с сердечком, список и источники.
4. **Календарь, Блокнот, Здоровье, Забота**, затем остальные инструменты «Моего мира».
5. **Почта, сообщения и рабочие чаты** — единый ввод, заголовки, возврат, нативные реакции.
6. **Бизнес и управление** — роли директора/сотрудника, поручения, документы, кадры.
7. **Браузер и межэкранная проверка** — согласованные темы, поисковая строка, док, возврат.

## Условия готовности каждого экрана
- Нет случайных заливок/рамок/дублирующих заголовков; ощущается частью Главной.
- Тема Белая / Графит / Изумруд проверена, иконки и типографика едины.
- Работают переходы, касания, возврат, клавиатура, реальное состояние данных.
- Нет горизонтального переполнения/полос прокрутки поверх композиции.
- Код не содержит новых дублирующих CSS-правил; соответствующие старые правила удалены.
- Проверка зафиксирована по факту — кодовая или визуальная, не на словах.

> Принцип работы: **удаляем лишнее, не добавляем украшения**. Сохраняем то, что уже получилось красиво.
