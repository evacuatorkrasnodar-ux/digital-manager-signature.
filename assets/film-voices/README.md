# SEYVEO · Естественные голоса демофильма

Для фильма предусмотрены **два отдельных AI-озвученных трека** по 14 глав: `felix/01.mp3` … `14.mp3` и `milissa/01.mp3` … `14.mp3`.

**Сейчас в репозитории пока нет готовых звуковых файлов.** В этом случае фильм полностью проходит автоматически **с титрами**, не используя роботические голоса iOS, Windows или Android. После генерации MP3 озвучка подключится без изменения фильма.

Для генерации понадобится платный API OpenAI и личный ключ. Ключ должен быть **только в GitHub Actions Secrets** или на локальном Windows-компьютере в переменной окружения `OPENAI_API_KEY`, но никогда в коде, чате или файлах сайта.

1. Добавить `OPENAI_API_KEY` в GitHub: Settings → Secrets and variables → Actions.
2. Actions → **SEYVEO film voices (manual only)** → Run workflow → выбрать **sample** и **both**.
3. Послушать пробные голоса на русском. Изначальные кандидаты: **cedar** для Феликса, **coral** для Милиссы (это не гарантия пола звучания).
4. Если устраивают — запустить ручной вариант **full**. Записи будут добавлены в репозиторий автоматически.

Стоимость голосов оплачивается отдельно по тарифам API. Workflow **не запускается автоматически** и не делает запросы к API при открытии PWA. Не запускайте полную генерацию, пока не проверите тестовые записи.

Альтернатива: `node scripts/generate-film-voices.mjs --sample` или `--full` с ключом только в переменной окружения на ПК.

Озвучка синтезирована ИИ — сообщаем об этом зрителям. **Голос ChatGPT внутри приложения ChatGPT не копируется**: используется отдельный TTS API. Настоящая голосовая беседа и система поддержки 24/7 требуют отдельной защищённой инфраструктуры и пока не реализованы.
