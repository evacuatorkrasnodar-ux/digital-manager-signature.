# SEYVEO · Дорога к делу

Экран «Новое дело» показывает блок «Дорога к делу», только если Сэйви нашла и подтвердила место на карте.

## Сейчас работает

- По разрешению пользователя определяется текущая отправная точка (не сохраняется в деле).
- На локальном сервере `server/real-app-local.mjs` `POST /api/seyveo-route-options` строит маршруты по реальным данным Яндекс Карт (авто, общественный транспорт, пешком) и при наличии отдельного ключа 2ГИС показывает проверенные номера автобусов/трамваев/маршруток.
- Время пути и пробки отображаются **только** если провайдер их вернул. Без доступа к API доступны внешние карты и ручной ввод минут — никаких выдуманных оценок.
- После выбора маршрута и запаса времени рассчитывается рекомендуемое время выхода. Оно сохраняется с делом; в «Моих делах» видны время выхода, маршрут и кнопка перехода в Яндекс Go.
- Яндекс Go открывается с заполненным пунктом назначения. **Заказ/планирование поездки и оплата происходят в Яндекс Go**, а не автоматически в SEYVEO.
- Системные уведомления о выходе включаются вручную; это локальные проверки во время работы приложения. Пуши при закрытом приложении и постоянный мониторинг пробок пока не поддерживаются.

## Настройка локального маршрутизатора

Установить переменные среды **на сервере**, не в HTML/JavaScript:

```text
SEYVEO_YANDEX_ROUTING_KEY=ваш_ключ_яндекс_маршрутизации
SEYVEO_2GIS_ROUTING_KEY=ваш_ключ_2гис_маршрутизации
```

Достаточно одного ключа; с 2ГИС показываются названия и номера реальных видов общественного транспорта. Оба сервиса требуют собственные условия доступа. Не коммитить ключи в репозиторий.

Публичный GitHub Pages не содержит серверного маршрутизатора, поэтому по умолчанию **не имеет онлайн-расчёта времени**. Пользователь может открыть внешний маршрут и ввести минуты вручную. Для полноценного публичного режима понадобится отдельный защищённый HTTPS backend, его авторизация и ключи маршрутизации.

Для проверки без API-ключей:

```bash
node --test tests/task-travel-core.test.cjs server/seyveo-route-service.test.mjs
```
