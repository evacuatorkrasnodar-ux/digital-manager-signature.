# SEYVEO — Единая шапка интерфейса (утверждено 12.11.2026)

## Эталон
Экран «Мои дела», утверждённый по скриншоту 12 ноября 2026 года.
Единственный источник чисел в коде: `assets/seyveo-header-system.css`.
Реализация Work использует те же CSS custom properties внутри собственного Shadow DOM:
`assets/seyveo-work-header.js`.

### Геометрия
- Контентная строка шапки: **62px**; поверх учитывается `env(safe-area-inset-top)`.
- На мобильных под вырез камеры: верхний отступ **16px + safe-area**; на широких экранах **24px + safe-area**.
- Левый и правый слоты: **42×42px**, радиус 50%.
- Сетка: **42px / эластичный центр / 42px**; межколоночный интервал **8px**.
- Заголовок: **20px**, вес **590**, межбуквенный интервал **−0.02em**, line-height **1.2**, строго по центру, независимо от количества кнопок.
- Стрелка «назад»: SVG **25×25px**, stroke **1.45**, круглые концы.
- «+» и контекстное действие: SVG **22×22px**, stroke **1.85** для плюса.
- Возврат — только реальное действие навигации; пустой правый слот не показывает фальшивый «+».

### Белая тема (эталон)
- Фон шапки: **#F2F1F6**, тёплый нейтральный.
- Надпись: **#1C1C1E**.
- Матовый кружок: `rgba(190,193,202,.43)`.
- Кромка: `1.75px solid rgba(255,255,255,.94)`.
- Материал: `blur(12px) saturate(108%)` и тонкие встроенные тени из общего CSS.
- Иконки: **#0B0B0D**.
- Никакой второй задней панели, выступающего борта, тяжёлой тени или цветного градиента.
- Следующий под шапкой сегмент — **#EDEDED**, без жёсткого разделителя.

### Тёмная тема (до отдельного утверждения)
- Фон: **#202023**.
- Заголовок: **#F6F6F8**.
- Кнопки: **#38383A**, без blur, лёгкая кромка `rgba(255,255,255,.14)`.

## Контракт экранов
1. **Одна** шапка на маршрут — избегать клонирования и наслаивания.
2. Слева «назад» только во вложенных разделах; в корневых не рисовать неработающие кнопки.
3. Справа одна действительно нужная контекстная кнопка. Поиск/плюс/готово только с подключённым обработчиком.
4. «Мои дела», календарь и блокнот-вкладка используют постоянную Work-шапку; при смене вкладки не скачут высота, title или слоты.
5. «Мой мир», Пульс, Управление, Документы и Почта используют общие токены для существующих заголовков. У них не создаётся вторая шапка.
6. **Блокнот**: самостоятельный список, текстовый редактор и редактор рисования сохраняют свои обработчики. Общие материал, стрелка и размеры применяются к существующим кнопкам, не создавая новых поверх холста.
7. **Здоровье**: существующие «назад» и «+» остаются интерактивными; общие размеры и материал только для верхнего ряда. Медицинские данные, контент, колесо ввода не меняются.
8. **Чаты**: не менять высоту панели ввода, голос, свайпы, активные диалоги; унифицировать только навигационные кнопки шапки при отдельном аудите.
9. На iPhone X и других устройствах с вырезом учитывать safe-area. Не допускать горизонтального скролла и смещения центра.
10. Новые экраны подключают общий CSS и помечают реальную шапку существующим классом/селектором, а не копируют цвета вручную.

## Проверка качества
- Снять скриншоты 320/375/390/430px, iPhone X и десктопа, белая/чёрная темы.
- Переключить «Мои дела ↔ Календарь ↔ Блокнот» без скачков шапки.
- Проверить «назад», «+», поиск, открытие/закрытие редактора и клавиатуры.
- Убедиться, что док, карточки, данные и нижние панели не затронуты.
