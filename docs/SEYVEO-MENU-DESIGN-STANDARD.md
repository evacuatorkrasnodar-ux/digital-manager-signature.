# SEYVEO · Единый стандарт меню V153

Действующая редакция: 26 ноября 2026. Предыдущие версии доступны в истории Git. Этот документ — единственный актуальный стандарт меню; старые значения не применять.

## 1. Материал и геометрия

| Параметр | Стандарт |
|---|---|
| Белая тема | rgba(249,250,251,.985) |
| Тёмная тема | rgba(41,43,48,.98) |
| Матирование | blur(20px) saturate(108%) |
| Рамка, тень | Единые токены --sv-menu-border и --sv-menu-shadow |
| Внешний радиус | 20 px |
| Радиус строки | 11 px |
| Высота обычной строки | Не менее 44 px; при длинной подписи увеличивать |
| Иконка | 20 × 20 px; линия 1.6 px, округлённые окончания |
| Текст строки | 14 px, вес 500, системный шрифт |
| Интервал иконка / текст | 10 px |
| Меню «Сообщения» | До 244 px, не шире доступного экрана |
| Раскрытие стандартного поповера | 160 мс; fade + scale, без постоянного transform |

Использовать плотное стекло, не прозрачность дока. Фон не должен мешать чтению. Разделители тонкие; опасные действия красные, остальные нейтральные. Существующие фирменные SVG сохраняются; отсутствующие иконки добавлять по смыслу, не текстовыми символами.

## 2. Реализация

Единый источник материала, радиуса, строк, иконок, состояния и анимации — `assets/seyveo-unified-menu-material.css`. Для новых поверхностей использовать `.sv-menu-surface`; для новых обычных действий — общую строку/класс, не изобретать отдельный материал. Существующие меню подключать проверенными селекторами. Локальные CSS отвечают за позицию, направление раскрытия, адаптивность и специальную сетку. Не дублировать общие параметры локально.

При ревизии удалять старые объявления только после проверки их селекторов, состояний и зависимостей. Не удалять целые файлы со смешанными функциями. Не применять общий стиль ко всем dialog, button или элементам, чьё имя содержит menu.

## 3. Поведение и доступность

- Открытие от существующей кнопки; позиционирование не должно выходить за экран или safe area.
- Сохранить действующие обработчики, выбранные состояния, права доступа, aria-expanded, aria-pressed, disabled, скрытые элементы и фокус клавиатуры.
- Не перехватывать прокрутку и касания холста. Не менять содержимое меню или назначение действий ради оформления.
- Снижение движения: без анимации; снижение прозрачности: плотный непрозрачный фон без размытия.
- Для палитр, календарных сеток, реакций и специальных инструментов сохранять их рабочую компоновку. Нативные системные пикеры, полноэкранные редакторы, доки, шапки, навигационные капсулы и нижние листы не подменять стилем поповера.
- Не менять данные заметок, документы, Undo/Redo, OCR, параметры кистей и навигацию при косметическом рефакторинге.

## 4. Область ревизии

Общий слой подключён в index.html и sayvi-chat-new.html. V151/V152 охватывает проверенные в исходниках меню сообщений, рабочих чатов, истории, Сэйви, семейных вложений, документов (в том числе папки и черновики), почты, блокнота, рисования, дел и собственных пикеров. В V152 удалён старый локальный материал меню «Сообщения»; добавлены SVG к семейным вложениям и исправлены состояния опасных и отключённых действий.

V153: контекстные меню отдельного дела и заметки переведены на общий слой, старые локальные заливки, рамки, радиусы и параметры строк удалены. Для действий дела используются SVG из общей библиотеки SEYVEO_DOCUMENT_ICONS до измерения положения меню. Встроенные раскрывающиеся действия карточек не приравниваются к поповерам.

Это не подтверждение полной визуальной проверки каждого динамического меню. Неучтённые селекторы подключать после проверки, а не создавать очередной независимый дизайн.

## 5. Критерии качества (обязательно перед утверждением)

- Одинаковый материал, ободок, радиус и оптическая ось строк.
- Нет просвечивающего текста, двойных рамок, скачков, наложений и обрезанных подписей.
- Фирменные иконки у обычных действий, корректный красный цвет удаления, читаемые отключённые состояния.
- Проверить открытие, закрытие, выбор, прокрутку, длинные подписи и фокус; белая и тёмная темы, iPhone (Safari/PWA), Android и ПК.
- Проверка CSS и ссылок в репозитории не заменяет реальную проверку интерфейса.

**Правило SEYVEO: один утверждённый материал и один стандарт меню. Любое исключение должно иметь функциональную причину.**
