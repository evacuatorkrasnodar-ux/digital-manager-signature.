# SEYVEO Learning Engine — первая локальная версия (30.10.2026)

## Два контура

- **Для одного человека**: добровольно подтверждённые короткие заметки памяти. Сохраняются локально через server/local-memory.mjs; доступны для удаления. Используются как справка при разговоре с локальной моделью.
- **Для всех (пока прототип)**: вымышленные обезличенные пары «вопрос — эталонный ответ». Сначала попадают в локальную очередь на ручную проверку. После одобрения — в локальную библиотеку server/approved-learning.mjs. **Другие пользователи их не получают.** Веса модели не меняются.

## Как открыть

1. Запустить существующий локальный сервер SEYVEO (server/start-real-seyveo.cmd на Windows).
2. Открыть http://127.0.0.1:8790/?seyveo_dev=1 в браузере того же компьютера.
3. Сверху справа появится кнопка «✦ Обучение · DEV».
4. В секции «Для одного человека» введите короткое предпочтение. Сохранение требует подтверждения. Любую запись можно удалить.
5. В секции «Для всех» укажите только **вымышленный пример** без настоящих клиентов, адресов, номеров, телефонов, почты и реквизитов. Поставьте галочку согласия и отправьте на проверку.
6. В списке «Ожидает решения» разработчик может нажать «Одобрить», «Отклонить» или удалить запись.

В обычном приложении без параметра seyveo_dev=1 панель скрыта. Скрипт не активируется за пределами localhost / 127.0.0.1. Карточки, сфера, док и навигация обычного приложения не менялись.

## Как работает

- Личная память и одобренные примеры добавляются отдельно как **справочный контекст** локальной модели через server/local-stream.mjs.
- Примеры передаются только при достаточном совпадении вопроса с уже одобренным примером. Они не должны переопределять правила ИИ и не означают, что внешнее действие выполнено.
- Нет автосбора переписки, отправки данных в облако или самозапуска обучения весов.
- Очередь хранится вне GitHub через server/learning-queue.mjs. **Файлы не зашифрованы на диске**: этот прототип не подходит для конфиденциальных бизнес-данных или медицинских сведений. Фильтры выявляют лишь некоторые признаки личных данных и не заменяют человеческую проверку.

## Локальные API

- GET /api/seyveo-learning-dashboard — статистика и очередь.
- POST /api/seyveo-learning-proposal — propose с confirmed=true, либо approve / reject / delete по id.
- GET /api/seyveo-memory, POST /api/seyveo-memory — уже существующая личная память.

Запросы ограничены loopback host и origin, но это ещё **не полноценная многопользовательская система**.
