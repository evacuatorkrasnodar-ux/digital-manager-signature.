# Сэйви рисует на ПК · первый реальный запуск

Эти действия выполняются **только на твоём Windows‑ПК**. Они не подключают облачную модель или iPhone к домашней сети. Личный Блокнот и образцы почерка остаются на устройстве.

1. Один раз установи [Ollama для Windows](https://ollama.com/download/windows) с официального сайта, запусти приложение Ollama. Также должен быть установлен Node.js (он уже используется локальным SEYVEO).
2. Обнови правильный GitHub-репозиторий `digital-manager-signature.` (с точкой на конце), ветка `main`, через **Fetch origin → Pull origin**.
3. В проводнике открой папку репозитория → `server` → дважды нажми **`start-paper-ai.cmd`**.
4. Если модели ещё нет, программа спросит разрешение скачать `qwen2.5vl:3b` (около **3,2 ГБ** плюс служебные файлы). Ответь `Y` только если хочешь скачать. Без подтверждения ничего не загружается.
5. Дождись строки «Модель готова» и открой [http://127.0.0.1:8790/](http://127.0.0.1:8790/) **на этом ПК**. Оставь чёрное окно запущенным.
6. В Блокноте выбери **Настройки → Действия → Попросить Сэйви**. Напиши, например, «Нарисуй дерево возле озера и две горы на фоне». После «Разобрать просьбу» появится **«Создать на ПК»**, только если Ollama действительно сообщает о наличии выбранной модели. Сначала будет предпросмотр. **«На лист»** применяет штрихи только после твоего нажатия, с обычной отменой действия.

Если модель недоступна, Сэйви объяснит причину: выключена локальная функция, Ollama не запущена или модель не установлена. Никаких декоративных новых кнопок не будет.

### Границы и безопасность

- `start-paper-ai.cmd` не устанавливает Ollama сам, не спрашивает пароль и не публикует сервер в интернет. Запросы SEYVEO направляются только на Ollama `127.0.0.1:11434`, SEYVEO слушает `127.0.0.1:8790`; `SEYVEO_ENABLE_CLOUD=0`. Скрипт **не меняет настройки уже работающей службы Ollama**: отдельно проверь, что сама Ollama не открыта на внешнем интерфейсе. Скачивание модели через официальную команду `ollama pull` происходит **только после выбора `Y`**.
- Наличие модели не гарантирует качество: Qwen2.5‑VL 3B может выдать грубый контур или неподходящий JSON. Сервер ограничивает ответ, проверяет геометрию, не меняет оригинал. Проверь рисунок перед вставкой. На ПК без отдельной видеокарты генерация может быть медленной.
- Это **локальный прототип**, не рабочая облачная Сэйви на iPhone. Для удалённого доступа нужны отдельный проверенный вход SEYVEO ONE, HTTPS, развёртывание API и тестирование iOS/Android. Не открывай порты Ollama/SEYVEO на роутере.
- Если окно закрылось, приложение перестанет отвечать. Запусти тот же файл снова. Если порт 8790 занят старой версией SEYVEO, останови только её через `Ctrl+C`, потом перезапусти.

Официальная модель: [qwen2.5vl:3b на Ollama](https://ollama.com/library/qwen2.5vl). Движок: `server/paper-vision-draft.mjs`; проверка готовности: `server/paper-model-health.mjs`; клиентский предпросмотр: `assets/seyveo-paper-ai-workbench.js`.
