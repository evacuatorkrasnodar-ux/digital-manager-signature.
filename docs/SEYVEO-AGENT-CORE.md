# SEYVEO Agent Core · первый шаг к цифровому управляющему

**Версия 0.1 — работающий модуль планирования, не автономный исполнитель.**

Феликс станет единой точкой входа для общения с Qwen3, GPT и инструментами SEYVEO. На этом этапе реализован только безопасный слой **«понять запрос → предложить план → не выполнять без подтверждения»**.

Это **не новая страница, не замена Главной и не имитация совершённых действий**. Существующие плазма Black Velvet, PWA, Ollama, заметки и календарь не изменяются.

## Что умеет код сейчас

Модуль `server/agent/planner.mjs` работает без платных моделей и без доступа к сети:

- «Создай встречу завтра» → предлагает три шага черновика календаря (`calendar.draft`).
- «Напиши письмо клиенту» → план черновика письма (`mail.draft`).
- «Запиши заметку» → план Блокнота (`notebook.draft`).
- «Исправь код в GitHub» → план проверки кода и diff (`code.proposal`).
- «Хочу открыть кофейню, составь бизнес-план» → план анализа (`business.research-plan`).
- «Оплати счёт», «Удали все документы», «Переведи деньги» → **отказ в исполнении**.

**Граница безопасности:** никакие запросы, включая «разрешаю», сейчас не приводят к записи в календарь, отправке письма, платежу, чтению контактов или изменению репозитория. В каждом ответе явно `executed:false`, `executionAllowed:false`, `approval.granted:false`, `toolsUsed:[]`. Предложенные шаги — только черновики. Нет доступа к почте/календарю/GitHub из этого модуля.

Это **простой классификатор по правилам**, а не интеллектуальный агент: он пока не извлекает даты, не изучает файлы и не вызывает модели. Мы создали границу между ИИ и потенциальными инструментами, на которую позже можно безопасно опираться.

## Быстрый запуск без установки пакетов

Из корня свежей версии GitHub (Node.js 22+):

```powershell
node server/agent/try-agent.mjs "Создай встречу завтра в 12:00"
node server/agent/try-agent.mjs "Исправь код в GitHub"
node server/agent/try-agent.mjs "Оплати счёт"
node --test server/tests/agent-planner.test.mjs
```

Никакой GPT API, Tailscale или запущенный Ollama для этого не требуется.

## Как модуль подключается к текущему приложению

- Локальная настоящая Главная с Qwen3 (`server/real-app-local.mjs`, `http://127.0.0.1:8790/`) теперь имеет `POST /api/seyveo-agent-plan` с JSON `{"message":"Создай встречу завтра"}`. Принимает только запросы с той же локальной страницы (Origin), не делает запись в разделы приложения.
- Закрытый iPhone-шлюз Tailscale Serve разрешает только этот дополнительный маршрут после проверки частного пользователя. Он не делает endpoint публичным.
- Сервер разработки `server/http.mjs` имеет `POST /v1/plan` с тем же `SEYVEO_DEV_TOKEN`, что и существующий защищённый `/v1/brain`.

**Пока на Главной нет кнопки для просмотра именно этого черновика**: мы сохранили её утверждённую структуру. Следующий этап — показать план в существующем пространстве ответа под сферой и связать с подтверждениями, не дублируя календарь, Блокнот и историю.

## Что будем развивать дальше

1. Структурированные черновики: извлечь событие/заметку/письмо, уточнить пропуски, показывать одну ясную карточку результата на iPhone.
2. Подтверждение с коротким временем жизни, токеном операции и журналом; разные разрешения для просмотра, создания черновика, сохранения и отправки.
3. Только затем адаптеры `calendar`, `notebook`, `mail` и `GitHub`. Изменения кода — через просмотр diff и тесты, не прямой произвольный shell.
4. Подключение GPT через серверные ключи (никогда не в PWA) и Qwen3 локально. Использование облака — отдельное разрешение и бюджет. Не отправлять частные данные в модель без правил.
5. Настоящая автономность — только в пределах явно согласованных правил и с безопасной отменой.

Проверка существующих серверных тестов:

```powershell
node --test server/tests/*.test.mjs
```

В репозитории добавлены автоматические тесты Agent Core и закрытого HTTP-подключения. **Живые испытания на iPhone и с Ollama ещё предстоят.**

Общие принципы: безопасные инструменты, ограниченные права, проверка результатов, отсутствие ложных сообщений об исполнении.
