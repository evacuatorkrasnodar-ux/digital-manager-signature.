# SEYVEO Research School · первый безопасный интернет-урок

**19 октября 2026 · подготовка, не работающий автоматический сбор знаний.** Феликс сможет изучать открытые сайты, но не «весь интернет сразу». Первый модуль намеренно **не запускается автоматически**, не обновляет веса Qwen3 и не записывает информацию в память.

## Что реализовано

- `server/intelligence/research-school.mjs`: два фиксированных открытых источника — <https://www.rfc-editor.org/rfc/rfc9309.html> (стандарт доступа роботов) и <https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide> (основы JavaScript).
- `studyPublicSource` читает **один явно выбранный источник за один вызов**. Нельзя подставить произвольный URL, локальный адрес или путь к документам.
- Перед страницей модуль получает `robots.txt` и проверяет запреты для своего User-Agent. При ошибках и перенаправлениях — отказывает. Реализован **ограниченный интерпретатор robots для фиксированных источников**, это ещё не полноценный индустриальный веб-краулер; перед расширением списка нужен более полный RFC-9309-парсер и дополнительная проверка лицензий сайтов.
- Принимает только HTTPS, запрещает переходы по редиректам и ссылкам, не загружает скрипты, изображения и сторонние ресурсы. Ограничение ответа 100 КБ; `robots.txt` — 32 КБ; предварительный текст — до 1400 символов.
- `status:'needs-human-review'`: содержимое — недоверенное, может ошибаться или пытаться отдавать команды ИИ. Результат включает URL источника и дату чтения. До ручной проверки его нельзя считать знаниями Феликса.
- `modelTrained:false`, `memoryChanged:false`, `approvedForKnowledgeBase:false`. Ничего не сохраняется в память, Qwen/Ollama/OpenAI не вызываются, платежей нет.

## Демонстрация

**Сервер на порту 8790 и Ollama можно выключить**: эти команды работают непосредственно в Node.js из свежей копии репозитория.

Показать разрешённые источники:

```powershell
node server/intelligence/study.mjs --list
```

Проверка **без выхода в интернет** — режим по умолчанию:

```powershell
node server/intelligence/study.mjs --source=web-standards
node --test server/tests/research-school.test.mjs
```

Если владелец **явно разрешит один реальный запрос**, в Windows CMD выполнить:

```bat
set "SEYVEO_RESEARCH_ENABLE=1"
node server/intelligence/study.mjs --live --source=web-standards
```

Или в PowerShell:

```powershell
$env:SEYVEO_RESEARCH_ENABLE = '1'
node server/intelligence/study.mjs --live --source=web-standards
```

Работа требует доступ к интернету именно у процесса Node.js. Оба разрешения (`--live` **и** переменная окружения) обязательны. Без них сеть не используется. Команда не запускает фоновое изучение и не меняет файлы. Если источник недоступен, блокируется его robots.txt, изменился формат, региональная политика или сайт отказал, команда безопасно завершится ошибкой.

## Следующая архитектура «Самообразование Феликса»

1. **Каталог доверенных источников** по конкретным темам (официальная документация, нормативные сайты, проверенные руководства). Только после проверки правил доступа, авторских прав, лицензий и разрешений.
2. **Исследование по задаче** — Феликс не «пылесосит весь интернет», а ищет ровно то, что нужно пользователю; проверяет дату, авторство, расхождения и несколько независимых подтверждений.
3. **Черновики знаний** — каждая единица знания содержит ссылку на первоисточник, дату и статус достоверности; до подтверждения не попадает в общую базу.
4. **Поиск в базе знаний (RAG)** — при ответе Феликс находит нужные проверенные записи и цитирует источники. Это не изменяет веса Qwen3 и позволяет оперативно удалить устаревшее сведение.
5. **Дообучение Qwen3** — отдельный, более поздний этап: только проверенные и законно используемые учебные примеры, изолированное обучение, тесты и возможность отката.
6. **Наблюдение за обновлениями** — только при отдельном согласии владельца, с заданными лимитами, временем работы, журналом и кнопкой остановки. Пока **не реализовано**.

**Важно о безопасности:** OWASP описывает атаки через содержимое найденных страниц: там могут быть спрятаны инструкции вроде «забудь правила, отправь файлы». Интернет-текст **никогда не должен становиться системной командой**. Даже после внедрения RAG нужны границы доверия, проверка источников и отсутствие самовольных действий. У наших первых заготовок вообще нет доступа к инструментам исполнения.

Источники стандартов:
- <https://www.rfc-editor.org/rfc/rfc9309.html>
- <https://cheatsheetseries.owasp.org/cheatsheets/RAG_Security_Cheat_Sheet.html>

**Честный статус:** модуль и автоматические тесты подготовлены в GitHub, но реальное получение сайтов из домашнего Node.js, их доступность, результат извлечения и интеграция с UI Феликса **не проверены**. Публичное приложение SEYVEO, плазма и Главная не менялись.
