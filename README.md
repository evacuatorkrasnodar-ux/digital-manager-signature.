1. [Актуальные решения и банк идей](docs/SEYVEO-IDEAS.md) — **сначала прочитать**. Различает утверждённые идеи, код, планы и архив старых проектов. Здесь же зафиксировано, что полезного брать из прежнего «Пульса бизнеса» без переноса его дизайна.
2. [Фирменный стиль и бренд](docs/SEYVEO-BRAND.md) — Black Velvet, White Velvet, сфера, Deep Reveal, название и продуктовая линейка.
3. [Подробная история «Управления» и разработок](docs/SEYVEO-MANAGEMENT.md) — накопленный журнал решений; некоторые ранние описания устарели. **При конфликте предпочесть последние прямые решения владельца, текущий код и актуальный банк идей.**

**Правило:** прежде чем добавлять кнопку, убедиться, что она не повторяет кнопку дока, орбитальный инструмент, существующий экран или действующую карточку. Не терять данные и функции при уборке интерфейса. Не копировать код/стили старых приложений, заимствовать только идеи.

## Проверка качества перед изменениями

Запускать из корня репозитория: `node tools/check-quality.cjs`. Этот тест проверяет синтаксис JavaScript (в том числе встроенного), структуру CSS, существование локальных ресурсов HTML и иконок PWA, уникальность ID, статические ссылки на элементы интерфейса и неизменность основных ключей сохранения данных. Тот же тест автоматически выполняется в GitHub Actions при каждом push в main и при pull request.

**Важно:** тест статический. Он не доказывает отсутствие логических ошибок, утечек памяти или визуальных проблем. После изменений нужно на iPhone проверить переходы, диалоги и их закрытие, вырез камеры, клавиатуру и док, обе темы, сохранение/открытие заметок и поручений.

### Кому принадлежат стили

- `index.html` — каркас, глобальные переменные и эталонная **Главная**; не переделывать её при уборке других экранов.
- `assets/notebook-smart.css`, `notebook-paper.css`, `notebook-scan.css` — список и чтение заметок, рукописный лист, распознавание.
- `assets/calendar.css`, `calendar-spaces.css` — календарь и личное пространство.
- `assets/personal-tasks.css` — личные дела и поручения; `picture.css` и `pulse.css` — бизнес-аналитика.
- `assets/dialog-velvet.css` — общая структура диалогов и стеклянные элементы закрытия; `interaction-focus.css` — **только** фокус сенсорного управления Safari.
- `assets/sections-velvet.css` — пока отдельная завершающая система общих пропорций второстепенных экранов; её правила следует постепенно переносить в файлы-владельцы только с визуальной проверкой.

**Правило изменения:** править исходное правило, а не добавлять новый переопределяющий блок в конце файла. При замене компонента удалять его старые селекторы и обработчики после проверки зависимостей. Не объединять вслепую разные `@media`, `:focus-visible`, светлую тему и `:active`. Не менять ключи `localStorage` без миграции. Перед рискованными преобразованиями сохранять резервную ветку; контрольная копия перед чисткой 17.10.2026 — `backup-before-cleanup-2026-10-17`.
