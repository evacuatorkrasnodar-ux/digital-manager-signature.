# SEYVEO Voice Engine · личный голос (30.10.2026)

## Что уже работает
В папке `server/seyveo-voice-school` есть `clone_wife_voice.py`: он подготовил 12-секундный WAV-фрагмент из записи жены (с её согласия), а модель Qwen3-TTS Base успешно сделала `seyveo-wife-preview.wav` на её компьютере.

Новый `say.py` произносит **произвольную короткую фразу** тем же голосовым образцом. Это локальный эксперимент на Windows: пока **не встроено в интерфейс Feather Chat** и не работает в фоне автоматически. Запись жены и результаты не надо добавлять в GitHub или публиковать. Согласие для использования голосовой личности в коммерческом приложении нужно оформить отдельно; его можно отозвать.

## Запуск Windows (из любого CMD)

```cmd
py -3.11 C:\SEYVEO-GitHub\server\seyveo-voice-school\say.py --text "Привет! Я Сэйви. Как прошёл твой день?"
```

Фраза сохраняется по умолчанию в:

`%LOCALAPPDATA%\SEYVEO\voice-school\seyveo-spoken.wav`

Можно открыть её двойным нажатием. Если нужны другие слова, поменяйте текст после `--text`. Максимум 500 символов. При следующем запуске файл перезапишется. Для разных файлов укажите `--out` с путём вне GitHub.

Скрипт загружает модель при каждом запуске, поэтому на CPU это пока медленный режим, а не живой разговор. Требуются установленные `torch`, `qwen-tts`, `soundfile`, 32 ГБ RAM и уже скачанные веса Qwen3-TTS Base. Первый запуск может проверить кеш и загрузить недостающие файлы. Текст и WAV не передаются через приложение SEYVEO в облако.

## Безопасность и следующие этапы

1. Локально проверить несколько фраз: естественность, русский, цифры, мягкие звуки и узнаваемость.
2. Сделать *локальный* процесс синтеза с единственной загруженной моделью и управлением очередью, прерываниями и задержкой.
3. Подключить к Feather Chat кнопку прослушивания **по нажатию**, без автоматического озвучивания личных чатов и без передачи аудио в GitHub. Предусмотреть выключатель, удаление образца и явное согласие владельца голоса.
4. Для нативных iOS/Android отдельно спроектировать оптимизированный движок или сервер синтеза с согласием пользователей. Нельзя обещать мгновенный голосовой диалог на CPU.

Важно: `--text` пока вводит человек вручную; сама Сэйви не начнёт читать ответы в чате после одного `git pull`.
