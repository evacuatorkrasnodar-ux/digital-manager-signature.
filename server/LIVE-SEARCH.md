# SEYVEO · Живой интернет-поиск

Работает через **уже существующий локальный сервер** `server/real-app-local.mjs` на `http://127.0.0.1:8790`. Не требует отдельного чата и не изменяет локальную память.

## Подключение

Поставщик первого этапа — официальный **Brave Search API**. Нужен собственный действующий ключ доступа. Не вставляйте ключ в GitHub, файлы приложения или скриншоты.

1. Создайте ключ Brave Search API в панели провайдера и проверьте действующий тариф/квоты.
2. На компьютере настройте переменную окружения `SEYVEO_BRAVE_SEARCH_API_KEY` для процесса, который запускает `server/start-real-seyveo.cmd`.
3. Перезапустите сервер; затем откройте страницу SEYVEO и спросите: «Правда ли Маск показал летающий Roadster?».

Если ключ не установлен, Сэйви честно скажет, что живой поиск пока не подключён. Офлайн-помощник и личная память продолжают работать отдельно.

## Как устроено

- Веб-поиск выбирается только для публичных вопросов о свежих событиях и явных запросов поиска. Вопросы с очевидным личным контекстом остаются в локальном диалоге.
- Браузер обращается только к своему локальному серверу `POST /api/seyveo-live-search`. На внешний сервис отправляется только текст конкретного поискового вопроса, **без истории переписки, памяти, контактов или файлов**.
- Ключ виден только серверному процессу и передаётся Brave в HTTPS-заголовке.
- Сервер разрешает максимум 10 запросов за минуту, ограничивает длину вопроса, отбрасывает небезопасные ссылки и прекращает ожидание провайдера через 12 секунд.
- Вывод: текст-пояснение и проверяемые ссылки на публикации. **Фотографии не придумываются и не загружаются автоматически**, пока нет проверенных лицензий и атрибуции.
- Обычный API-план не разрешает постоянное хранение выдачи. Карточки источников живут только в текущем чате до перезагрузки; история сохраняет вопрос и общий статус, но не результаты или фрагменты чужих страниц. Прежние сохранённые выдачи удаляются из браузерной истории при загрузке. Для постоянного хранения нужны соответствующие права по договору с провайдером.
- Для коммерческого запуска потребуется сообщение пользователям об отправке публичного поискового запроса внешнему поставщику и необходимые согласия.
- Кнопка «Стоп» отменяет запрос в браузере. Она не гарантирует отмену уже начатого оплачиваемого запроса у провайдера.
- Это поиск по источникам, а **не** полноценное нейросетевое исследование: проверка содержания и синтез ответа с цитатами требуют отдельного защищённого ИИ. API-результаты не используются для обучения SEYVEO.

## Проверки

`node --test server/live-search.test.mjs tools/test-live-search-request.cjs`

Для проверки HTTP-обработчика:

`node --test server/tests/real-app-local.test.mjs`

Никогда не включайте тестовый ключ в коммиты и логи.
