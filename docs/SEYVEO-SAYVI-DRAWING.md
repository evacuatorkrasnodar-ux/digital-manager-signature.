# SEYVEO · Сэйви: творческая мастерская рисования
Дата постановки: 2026-11-21  
Статус: утверждённая продуктовая постановка. **Наличие кнопки не означает работающую ИИ-функцию.**

## Принцип
Мастерская Сэйви — интеллектуальная помощь с художественным холстом, а не вторая панель обычных инструментов. Не дублировать «Добавить текст», «Добавить фото», OCR рукописи, кнопки выбора цветов и другие инструменты редактора. OCR, запоминание почерка и преобразование рукописи в текст относятся к Блокноту. Одна кнопка Сэйви в верхнем доке открывает мастерскую; отдельное действие в мастерской ведёт в чат с сохранением текущего листа через существующий безопасный путь.

## Зафиксированные возможности

| ID | Кнопка | Смысл | Фаза / текущая реализация |
|---|---|---|---|
| `smooth` | Выровнять линии | Делать дрожащие линии, штрихи, прямые и контуры аккуратнее, сохраняя исходник и сравнение до/после | Работает локально через `notePaperSmoothInk`; требует проверки на устройстве |
| `shape` | Узнать фигуру | Узнавать некоторые формы в наброске (дом, сердце, овал, буква С), предлагать ровный контур | Ограниченная локальная реализация в меню «Это…»; не универсальное зрение |
| `draw` | Нарисовать | По тексту создать рисунок новыми векторными штрихами | Ограниченный локальный путь /api/seyveo-paper-draft на ПК при установленной и запущенной модели; на публичном сайте без модели недоступно |
| `extend` | Дорисовать | Продолжить незаконченную линию или композицию на основе имеющихся штрихов | Задумано, требуется модель с доступом к контексту холста |
| `colorize` | Раскрасить | Предложить цветовое решение для готового рисунка/замкнутых областей без ручного подбора каждого цвета | Задумано, нужна сегментация/кисть/слои |
| `style` | Изменить стиль | Варианты карандаш, акварель, комикс, линейная графика; предлагать предпросмотр | Задумано, нужна модель и безопасное представление стилей |
| `erase` | Убрать лишнее | По выбору пользователя удалить конкретный предмет/лишнюю деталь, сохранив остальное | Задумано, нужны выделение области и интеллектуальная обработка |
| `enhance` | Улучшить рисунок | Сделать контуры/детализацию/композицию выразительнее, не меняя замысел автора без разрешения | Задумано |
| `understand` | Понять рисунок | Объяснить, что изображено, и предложить развитие рисунка без ложной уверенности | Задумано, нужна визуальная модель |

## UX-контракт
1. В первом экране показать компактные готовые творческие действия, обычные инструменты редактора не добавлять.
2. Фаза 1: `smooth` и ограниченное `shape` открывают имеющиеся редактирующие действия.
3. Для любой будущей функции выбор заполняет осмысленную просьбу. Показывать «В планах» / «Нужна модель», не обещать готовый рисунок и не изменять исходник.
4. При установленной модели действие `draw` может показать подтверждаемый предпросмотр, который проходит строгую проверку формата; остальные задачи не должны автоматически превращаться в вызов `draw`, потому что это разные операции.
5. Любая работа модели: исходник неизменен до подтверждения; предпросмотр «До/После»; «Применить», «Отмена», доступная история Undo; не редактировать незаметно.
6. На iPhone/Android элементы должны быть компактными, прокручиваться без наложений, не блокировать рисование по краям. Белая тема SEYVEO; чёрная — после.
7. Избегать новых дублирующих меню и вторых кнопок Сэйви. Градиенты системного выбора цвета не дублировать.
8. Техническую информацию о модели показывать только по запросу в «Как работает Сэйви».

## При будущем подключении и обучении
- Подготовить набор примеров: текст просьбы, нормализованная область холста, исходные штрихи, ожидаемый вариант результата, ожидаемый запрос подтверждения. Не включать пользовательские рисунки без отдельного согласия.
- Разделить модели или инструменты: (а) понимание наброска; (б) улучшение векторных линий; (в) генерация/продолжение штрихов; (г) раскраска/стилизация; (д) объектное удаление. Текстовый планировщик сам по себе не выполняет рисование.
- Для каждого ID создать адаптер `canRun()`, `preview()`, `applyAfterConfirmation()`, `undo()`, статус «не подключено / готово / не удалось».
- Не подменять неудобные ситуации выдуманным результатом. При отсутствии модели в публичном PWA объяснять, что функция ещё не подключена.
- Проверить производительность/отзывчивость на iPhone 10 и Android, поддержку пальца и стилуса, границы холста и сохранение рисунка.
- Перед запуском: независимые тесты распознавания и качества, ручное сравнение до/после, проверка Undo, отказов модели, локальной приватности и случаев пустого холста.
