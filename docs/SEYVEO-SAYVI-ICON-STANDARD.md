# SEYVEO · Единый знак Сэйви

**Утверждено 21 ноября 2026.**

## Единственный эталон

**Форма:** чёрная круглая переплетённая буква **S** (монохромный фирменный знак SEYVEO). Ровно этот знак выбран по пользовательскому образцу, а не четырёхлучевая звезда.

**Мастер-файл:** `assets/seyveo-circular-interlace-mono.svg`.

**Общий UI-адаптер:** `assets/sayvi-mark.css`. Все небольшие значки Сэйви, в том числе внутри карточек, меню, подсказок и кнопок настройки кабинета, используют существующий класс `.sv-sayvi-symbol` или его предусмотренные псевдоэлементы. CSS-маска ссылается напрямую на мастер-файл.

## Обязательные правила

1. Не рисовать новый значок Сэйви в HTML, JavaScript или CSS; не добавлять отдельные SVG, символы ✨, четырёхлучевые звёзды и голубые копии для обозначения Сэйви.
2. Не менять оригинальный силуэт, пропорции, внутренние прорези и скругления. Меняется только размер и чернила по теме: чёрный/тёмный в светлой, светлый в тёмной.
3. Для каждого нового UI-элемента использовать `<span class="sv-sayvi-symbol" aria-hidden="true"></span>`, а для доступности дать читаемое название управляющей кнопке.
4. Не превращать этот знак в обычную иконку «избранное», «праздник», «помощь» или «важно»: у семантических значков собственные формы.
5. Сфера на главном экране, материал круглой кнопки дока, кино-заставка, PWA-иконки и фирменные цветные элементы не подменяются плоским значком автоматически. Это отдельные согласованные поверхности. При появлении маленькой иконки именно Сэйви использовать данный эталон.
6. Не хранить параллельный устаревший `sayvi-mark.svg`: он удалён. Не восстанавливать `svCabinetSayviFill` / `sv-cabinet-sayvi-emblem`, ранее вручную рисовавшие голубую звезду в кабинете.

**Проверка:** «Кабинет → Настроить с Сэйви», чат, рабочие поручения, подсказки, документы, почта, доступные варианты тем. Везде, где нужен именно маленький знак Сэйви, отображается одна и та же S.
