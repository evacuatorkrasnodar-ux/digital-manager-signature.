# SEYVEO · настоящий Феликс на iPhone (закрытый этап)

**Статус:** код закрытого шлюза и тесты подготовлены. Реальное соединение с iPhone и Tailscale ещё не настроено и не проверено.

## Суть

Не создаём отдельный дизайн и не переделываем публичную Главную. На iPhone будет открываться **тот же index.html и assets нашего приложения SEYVEO**, но с настоящим Qwen3 4B через серверный мост. Для частного испытания используем отдельный защищённый адрес Tailscale Serve, а не публичный GitHub Pages.

Маршрут:

    iPhone Safari (Tailscale)
       → HTTPS Tailscale Serve (только закрытая tailnet)
       → 127.0.0.1:8791 (iphone-private-gateway.mjs)
       → 127.0.0.1:8790 (real-app-local.mjs: основная Главная)
       → 127.0.0.1:11434 (Ollama: qwen3:4b-instruct)

Tailscale Serve — это частный HTTPS-прокси, в отличие от публичного Funnel. Никакого проброса портов роутера.

## Что в коде

- server/iphone-private-gateway.mjs: Node-сервер только на 127.0.0.1. Требует точный адрес устройства в домене *.ts.net и логин владельца из заголовка Tailscale-User-Login, который добавляет Tailscale Serve. Без них отклоняет запрос.
- Дополнительно проверяются Host, Origin, sec-fetch-site, путь и допустимый метод. Запросы к файлам server/ запрещены; никакого произвольного проксирования URL нет.
- Ответ модели передаётся постепенно в том же формате NDJSON, без изменения Ollama и локальной памяти.
- server/tests/iphone-private-gateway.test.mjs проверяет ограничения и потоковый ответ на подставном сервере. Это ещё не тест настоящего iPhone.
- server/start-felix-iphone-private.cmd — интерактивный запуск на Windows. Значения адреса и логина вводятся при старте; в репозитории не хранятся.

**Внимание:** идентификация по заголовку допустима здесь только потому, что Node слушает 127.0.0.1, а удалённые запросы проходят через доверенный Tailscale Serve. Программа, запущенная на самом Windows-ПК, может подделать такой заголовок, поэтому необходима защита компьютера. Это прототип одного владельца, не промышленная авторизация.

## Что сделать для реального запуска

1. Установить официальное приложение Tailscale на Windows с Ollama и на iPhone. Войти в свою tailnet на обоих устройствах, включить разрешённый доступ и HTTPS. Найти точный DNS-адрес компьютера в формате имя-компьютера.имя-сети.ts.net, а также свой логин Tailscale.
2. Получить свежую версию репозитория GitHub. На ПК сначала запустить server/start-real-seyveo.cmd, убедиться в работе страницы http://127.0.0.1:8790/ и ответов Феликса. Окно оставить открытым.
3. Во втором окне запустить server/start-felix-iphone-private.cmd; указать точное имя *.ts.net и свой логин. Шлюз начнёт слушать только 127.0.0.1:8791. Окно оставить открытым.
4. В третьем терминале Windows вручную включить **Serve, НЕ Funnel**:

        tailscale serve --bg 8791
        tailscale serve status

   В выводе должно быть «Available within your tailnet» с HTTPS-адресом и проксированием на http://127.0.0.1:8791.
5. На iPhone включить Tailscale и открыть этот HTTPS-адрес в Safari. Перед вами основная Главная SEYVEO, в которой свободные вопросы должен отвечать локальный Феликс. Проверить клавиатуру, 2–3 последовательных сообщения, текст в потоке.
6. Отключить доступ можно командой, поддерживаемой установленной версией Tailscale Serve; смотрите вывод tailscale serve --help. Команда tailscale serve reset сбрасывает все Serve-настройки этого устройства. Закрыть окна шлюза и локального сервера.

Если виден 403 — проверить точность DNS-имени, владельца и подключение Tailscale, **не отключать защиту и не включать Funnel**.

## Ограничения

- ПК с Ollama должен быть включён и доступен. На самом iPhone Qwen3 не запускается.
- Публичный GitHub Pages останется с демонстрационными ответами. **Приватный HTTPS-адрес другой**, хотя дизайн и код Главной общие.
- Из-за другого адреса локальное хранилище, заметки и настройки из GitHub Pages не переносятся; не выполнять автоматическую синхронизацию.
- Пока только ответы. Ни платежи, ни почта, ни звонки, ни доступ к контактам, ни изменение календаря не разрешены.
- Это не общедоступный сервис: нет пользовательских аккаунтов, полномасштабной защиты данных, резервного копирования и готовой серверной инфраструктуры. Токены/ключи никогда не вставлять в публичный JS.
- Для массового использования без Tailscale нужна отдельная архитектура: аутентифицированный HTTPS API, разграничение пользователей и явные разрешения на действия.
- Голос браузера может зависеть от внешнего сервиса даже в частном приложении.
